# Publishing Guide (GitHub)

## Recommended repository title

`wae-router-e2e-handoff`

## Suggested commit sequence

1. `chore: add handoff repository skeleton and runbook`
2. `docs: add round7r2 progress snapshot and known issues`
3. `feat: include reproducible scripts/config for round orchestration`

## Do not commit

- `.venv/`
- raw full `runs/` directories
- private tokens / keys

Include only curated artifacts under `artifacts/`.
